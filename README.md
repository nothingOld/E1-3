# Mini NPU Simulator

AI의 기본 반복 연산인 MAC(Multiply-Accumulate) 을 Python 반복문으로 직접 구현하고,  
Cross/X 필터와 입력 패턴의 점수를 비교하여 패턴을 판정하는 콘솔 프로그램입니다.

외부 라이브러리(NumPy, pandas 등)를 사용하지 않고 Python 표준 라이브러리만 사용합니다.

## 필터와 패턴 그리고 중요한 핵심 개념 4개

### 필터(filter)란?

- 미리 알고 있는 기준 데이터(모양)으로 입력 데이터와 비교할 기준 데이터

### 패턴(pattern)이란?

- 사용자가 입력한 데이터로 판별해야 하는 대상
- 즉 "이 입력이 + 인지 X인지 "

### 행렬 / 2차원 리스트

- 행(row), 열(column)
- 원소(element)
- matrix[row][col]
- N×N 행렬
- 파이썬 list 안에 list로 2차원 리스트 구성

### MAC 연산

**이번 미션 핵심 개념**

- MAC(Multiply-Accumulate)은값을 곱한 뒤(Multiply), 그 결과를 계속 누적해서 더하는(Accumulate) 연산입니다.
- 기본 형태는 A × B + C이며, 여러 값에 반복 적용하면 각 위치의 값을 곱한 결과를 모두 합산하여 하나의 결과값을 만드는 방식입니다.
- MAC 연산은 인공지능/딥러닝의 행렬 연산, 신경망 계산, 디지털 신호 처리(DSP), 이미지 처리 등에서 반복적으로 사용되는 핵심 연산입니다.

**이번 미션에서의 MAC 연산**

- 입력 패턴과 필터가 같은 크기의 행렬이라면, 같은 행·열 위치에 있는 원소끼리 곱하고 그 결과를 모두 더해 하나의 점수를 계산합니다.
- 패턴 자체의 MAC 점수가 따로 존재하고 필터 자체의 MAC 점수가 따로 존재하는 게 아닙니다.
- MAC 점수는 패턴과 필터를 한 쌍으로 넣어서 계산한 유사도 점수라고 이해하면 됩니다.

### 부동소수점 + epsilon(엡실론)

- 컴퓨터가 실수를 표현하는 방식입니다. 일부 십진수는 2진수로 정확하게 표현할 수 없기 때문에 계산 과정에서 아주 작은 오차가 발생할 수 있습니다.
- 예를 들어 수학적으로는 같은 값으로 생각할 수 있어도 실제 계산 결과는 0.9와 0.8999999999999999처럼 미세하게 다르게 나타날 수 있습니다.
- 이런 값을 단순히 ==, >, <로 비교하면 미세한 계산 오차 때문에 의도하지 않은 판정이 발생할 수 있습니다.
- epsilon(ε)은\*이러한 두 실수의 차이를 어느 범위까지 같은 값으로 인정할 것인지 정하는 허용오차 기준값입니다.
- 이번 미션에서 epsilon은 `1e-9`로 정의 했는데 이유는 아래와 같습니다. 하지만 절대값은 아닙니다!
  - 부동소수점 정밀도 범위 내
  - 실제 데이터 스케일에 비해 충분히 작음
  - 수치 안정성과 정확도의 최적 지점
  - 대부분의 라이브러리에서 기본값으로 사용

### 시간복잡도 O(N²)

- 성능 분석 개념
- 입력 크기가 증가할 때 알고리즘의 연산량이 어떤 형태로 증가하는지 나타내는 개념입니다.
- O(N²)은 입력 크기 N이 커질수록 연산량이 N의 제곱에 비례하여 증가한다는 의미입니다.
- N×N 행렬은 N개의 행과 N개의 열을 가지므로 전체 원소 수는 N × N = N²개입니다.
- 이번 미션의 MAC 연산은 입력 패턴과 필터의 모든 원소를 한 번씩 처리하므로 연산량도 N²에 비례합니다.
- 따라서 행렬의 한 변의 크기 N이 2배가 되면 연산량은 약 4배, 3\*가 되면 약 9배가 됩니다.
- O(N²)은 실제 실행 시간이 정확히 몇 초 또는 정확히 몇 배가 된다는 의미가 아니라, 입력 크기에 따른 연산량의 증가 추세를 나타냅니다.

### JSON 구조와 라벨 정규화

- 이번 미션에서는 data.json에 패턴, 필터, 정답 라벨 등의 정보를 저장하고 프로그램이 이를 읽어 사용합니다.
- 프로그램은 size_5, size_13 같은 키 이름의 규칙을 해석해 해당 패턴의 크기와 사용할 필터를 결정할 수 있습니다.
- 라벨 정규화(Label Normalization)는 같은 의미지만 표현이 다른 라벨들을 프로그램 내부에서 하나의 표준값으로 통일하는 과정입니다.
- JSON은 패턴과 필터 등의 데이터를 일정한 키 규칙으로 저장하는 형식이고, 프로그램은 그 키 규칙을 해석해 필요한 데이터를 선택합니다.
- 라벨 정규화는 x, X 또는 +, cross, Cross처럼 표현은 다르지만 의미가 같은 값을 하나의 표준 라벨로 통일하여 잘못된 비교를 방지하는 과정입니다.
- 특히 이번 미션에서는 JSON = 데이터 구조와 규칙, 라벨 정규화 = 표현 차이를 제거하고 의미를 통일이라고 구분해서 기억하면 됩니다.
